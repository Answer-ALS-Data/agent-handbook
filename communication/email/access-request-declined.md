# Access request declined

## When to use

The Data Access Committee declined the request, or the team closed it because it could not be completed.
Send only after the decision is final and the reason has been agreed with the Data Access Committee.

## Subject

Your Neuromine data access request

## Body

Hi [First name],

Thank you for your interest in [Program] data on the Neuromine Data Portal. The Data Access Committee has reviewed your request, and we are not able to approve it as submitted.

[Reason, as agreed with the Data Access Committee]

[What the requester can do next]

If you have a question about this decision, reply to this email and we will pass it to the committee.

[Sender name]
[Program] data team, data@answerals.org

## Fill in

- [First name]: the requester's first name.
- [Program]: Answer ALS or ALS TDI, as on the request.
- [Reason, as agreed with the Data Access Committee]: one or two plain sentences with the reason the committee gave. Add no reasons of your own.
- [What the requester can do next]: for example "If your project changes, you are welcome to submit a new request on the Datasets tab with an updated data use proposal." Delete the line if the committee said there is no path.
- [Sender name]: the first name of the person sending.
