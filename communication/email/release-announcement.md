# Release announcement

## When to use

The data owner has confirmed a release is public on Neuromine and given the release date.
Send it to approved users the same day, never before the owner says the release is live.

## Subject

[Program] Release [Release number] is now on Neuromine

## Body

Hi [First name or all],

[Program] Release [Release number] is now available on the Neuromine Data Portal, as of [Release date].

What is new:

- [Change 1]
- [Change 2]
- [Change 3]

[What behaves differently]

The full release notes and the README are on the portal: [Release notes link]. If you already have access, the new files are on the Datasets tab at https://dataportal.answerals.org/datasets

[Sender name]
[Program] data team, data@answerals.org

## Fill in

- [Program]: Answer ALS or ALS TDI.
- [Release number]: the whole release number only, such as 8 or 2. Never a sub-release label such as r8.3.
- [First name or all]: the user's first name, or "all" for a list send.
- [Release date]: the date the data owner gave, written as October 20, 2026.
- [Change 1], [Change 2], [Change 3]: up to three changes, in the release notes' own words. Example: "Clinical data is updated with all available information from the September 2026 data delivery, covering 1,047 participants." Use no count that is not in the release notes. Delete unused lines.
- [What behaves differently]: one line, only if a saved filter, file name or field meaning changed. Example: "A saved filter on iPSC = Yes now returns all participants with a line; to keep the old behavior, filter on iPSC For Sale = Yes." Otherwise delete the line.
- [Release notes link]: the program's release notes page from answer-als/links/link-registry.csv. The registry still lists the old WordPress address for both release notes pages and marks it for update; use the new address once that link work is done.
- [Sender name]: the first name of the person sending.
