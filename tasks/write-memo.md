# Write a memo or one-pager

## What you get

A memo, letter or one-page summary in Word, built from the standard Answer ALS memo or one-pager template.

## Read first

- AGENTS.md
- design/README.md
- design/templates/docx-templates.md
- design/templates/build_docx_templates.py
- programs/answer-als.md
- programs/als-tdi.md

## Steps

1. If the person did not say who reads it, what decision or action it asks for and whether it is a memo, a letter or a one-pager, ask.
2. Start from the built template in design/templates/: answer-als-memo-template.docx for a memo or letter, answer-als-one-pager-template.docx for a one-page summary. docx-templates.md says where they are and how to use them. If a file is not there, build it with design/templates/build_docx_templates.py.
3. Copy the template and replace each bracketed instruction with text, inside its word limit. Use the named styles only.
4. Take counts only from programs/. Put a source line under any table or number.
5. Cut any section the document does not need. A memo is at most two pages and a one-pager is one page.

## Hand back

The .docx file, saved under a new name, plus a short note of any fact you could not fill. Never send the document to anyone. The person sends it.
