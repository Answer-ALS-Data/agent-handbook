# Review a draft against the house style

## What you get

A list of changes that bring the person's draft in line with the house writing rules and look.

## Read first

- AGENTS.md
- communication/README.md
- design/README.md

## Steps

1. If the person did not paste the draft or say what kind it is (email, slide text, memo, page), ask.
2. Check every line against How to write and Privacy in AGENTS.md: ASCII only, no exclamation marks, no banned words, short sentences, no participant data or keys.
3. For an email, also check Tone, Response shape and Never put in a message in communication/README.md. For a slide, memo or page, also check Voice on a page in design/README.md.
4. Check that each count is on a programs/ page and each fact you can check is right.
5. Write each change as the line as it is, the line as it should be, and the rule it breaks.

## Hand back

The list of changes, then the full revised draft as plain text. Never send the draft to anyone. The person sends it.
