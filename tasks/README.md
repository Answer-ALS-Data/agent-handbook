# tasks

Each page here is the recipe for one option on the menu in the "Give this to an agent" section of the handbook README (https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/README.md). The agent reads AGENTS.md, shows the menu, matches the person's answer to one option and fetches that option's page. Every page has the same four parts: What you get, Read first, Steps and Hand back. Every Read first entry is a raw URL to fetch.
