# Build a slide deck

## What you get

A slide deck for a talk or program update, made from the standard Answer ALS deck template.

## Read first

- https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/AGENTS.md
- https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/design/README.md
- https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/design/templates/deck-template.md
- https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/lou/INDEX.md

## Steps

1. If the person did not say the audience, the length or number of slides, the main point and the date, ask for them.
2. Fetch the template https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/design/templates/answer-als-deck-template.pptx (deck-template.md says how to use it).
3. Use the template as it is. Do not restyle it and do not rebuild it.
4. Plan one idea per slide and pick a layout from the table in deck-template.md.
5. Write each headline as the point, under 10 words. Take program facts and counts only as quoted from a Lou page, and add a source line naming that page under every chart and table.
6. Copy the template, duplicate the layout slides you need, replace their text and speaker notes, and delete the unused example slides.

## Hand back

The .pptx file, saved under a new name, plus a list of the slides with their headlines and any fact you could not fill. Never send the deck to anyone. The person shares it.
