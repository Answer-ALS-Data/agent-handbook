# Build a slide deck

## What you get

A slide deck for a talk or program update, built from the standard Answer ALS deck template.

## Read first

- AGENTS.md
- design/README.md
- design/templates/deck-template.md
- design/templates/build_deck_template.py
- communication/talks/program-update-outline.md
- communication/talks/data-walkthrough-outline.md
- programs/answer-als.md
- programs/als-tdi.md

## Steps

1. If the person did not say the audience, the length or number of slides, the main point and the date, ask for them.
2. Start from the built template answer-als-deck-template.pptx in design/templates/ (deck-template.md says where it is and how to use it). If the file is not there, build it with design/templates/build_deck_template.py.
3. For a program update or a data walkthrough, follow the matching outline in communication/talks/. Otherwise plan one idea per slide and pick a layout from the table in deck-template.md.
4. Write each headline as the point, under 10 words. Take counts only from programs/ and add a source line under every chart and table.
5. Copy the template, duplicate the layout slides you need, replace their text and speaker notes, and delete the unused example slides.

## Hand back

The .pptx file, saved under a new name, plus a list of the slides with their headlines and any fact you could not fill. Never send the deck to anyone. The person shares it.
