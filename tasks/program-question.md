# Answer a question about a program

## What you get

A plain answer about what Answer ALS or ALS TDI is, what it publishes, where it lives and its published counts.

## Read first

- AGENTS.md
- programs/answer-als.md
- programs/als-tdi.md
- communication/README.md

## Steps

1. If the person did not say which program, and it is not clear from the question, ask.
2. Answer from the program page. Published counts come only from programs/. Do not take a count from anywhere else and do not work one out.
3. If the question is about a release that is staged, not public, say so, as the program page does.
4. If the answer is not on the page, say you do not know and name the role to ask, from communication/README.md.

## Hand back

The answer in a few sentences, naming the program page it came from. Never send it to anyone. The person passes it on.
