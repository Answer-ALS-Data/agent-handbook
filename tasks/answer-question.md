# Answer a question

## What you get

A plain answer to a question about a program or about the data files, taken from the page that holds it, with that page named.

## Steps

1. If the person did not say which program (Answer ALS or ALS TDI) and it is not clear from the question, ask.
2. Route the question. A program, access, DUA, download, FAQ or contact question goes to the lou/ pages: find the page in lou/INDEX.md that fits and fetch it. A column, form, file, naming or validation question goes to data/: find the page in data/README.md that fits and fetch it.
3. For a Lou page, quote it. Do not rewrite it and do not take a count from anywhere else.
4. For a data/ page, answer with column names, types, codes from a dictionary and file layouts. Columns and layouts, never values. Do not open a data file and do not quote, count or hint at any row.
5. If the answer goes out as an email, use communication/email/data-question-reply.md as it is. Do not restyle it.
6. If no page has the answer, say you do not know and name the role to ask, from communication/README.md.

## Hand back

The answer in a few sentences, naming the page it came from by its raw URL. Never send it to anyone. The person passes it on.
