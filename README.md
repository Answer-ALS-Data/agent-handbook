# agent-handbook

This repo tells an AI agent how the Answer ALS data team works. It holds the programs we run, the house style for writing, the look of our pages, the shapes of our data files and reusable pieces for talking to users. It never holds data.

## Give this to an agent

Paste the link https://github.com/Answer-ALS-Data/agent-handbook to the agent, then say what you want in your own words. The agent reads AGENTS.md, shows you this menu, matches your answer to one option and follows that option's page in tasks/.

- Draft an email (tasks/draft-email.md): a reply or message to a user, partner or the team, in the house tone, ready for you to send.
- Build a slide deck (tasks/build-deck.md): a talk or program update made from the standard deck template.
- Write a memo or one-pager (tasks/write-memo.md): a memo, letter or one-page summary made from the Word templates.
- Create an SOP (tasks/create-sop.md): a standard operating procedure for a team process.
- Answer a question about the data files (tasks/data-question.md): what a column, form or file holds and how files join, from the schema pages.
- Answer a question about a program (tasks/program-question.md): what Answer ALS or ALS TDI is, what it publishes and its published counts.
- Review a draft against the house style (tasks/review-draft.md): a list of changes that bring your text in line with our writing and look.

If what you want is not on the list, say it anyway. The agent will tell you it has no recipe for it and ask how to go on.

## Folders

- AGENTS.md: the rules an agent reads first.
- tasks/: one page per menu option above.
- programs/: one page per program (Answer ALS, ALS TDI).
- design/: the look of our pages, decks and documents, with tokens.json, the logo and templates/ (the deck and Word template scripts and their how-to pages).
- communication/: reusable text for messages and talks: email/ (eight templates) and talks/ (two slide outlines).
- schemas/: column names and file layouts, never values.
- NOTES.md: choices made while building this repo.

## What an agent may do with it

- Read any file here and follow it.
- Suggest a change to a page by telling the person who gave the task.

## What an agent may not do with it

The rules are in AGENTS.md. In short: no data, keys or SAS strings, no reading data it was not given, no changes to the brand or the program facts on its own, and nothing sent on a person's behalf.

If a page here and the task disagree, ask the person who gave the task.
