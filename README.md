# agent-handbook

This repo tells an AI agent how the Answer ALS data team writes SOPs and user emails, how it writes and hands back work, and what our data files hold; it never holds data.

## Give this to an agent

Paste this line to the agent, then say what you want in your own words: Fetch https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/AGENTS.md and follow it. The repo is https://github.com/Answer-ALS-Data/agent-handbook. The agent prints this menu, matches your answer to one option and follows that option's page.

- Draft an email (https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/tasks/draft-email.md): a reply or message to a user, partner or the team, in the house tone, ready for you to send.
- Create an SOP (https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/tasks/create-sop.md): a standard operating procedure for a team process, in the house SOP template.
- Answer a question (https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/tasks/answer-question.md): about a program, access, the DUA, downloads or contacts from the Lou pages, or about a column, form, file, naming or validation from the data pages.
- Build a slide deck (https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/tasks/build-deck.md): a talk or program update made from the standard deck template.
- Write a memo or one-pager (https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/tasks/write-memo.md): a memo, letter or one-page summary made from the Word templates.
- Review a draft against the house style (https://raw.githubusercontent.com/Answer-ALS-Data/agent-handbook/main/tasks/review-draft.md): a list of changes that bring your text in line with our writing and look.

If what you want is not on the list, say it anyway. The agent will tell you it has no recipe for it and ask how to go on.
