## Below are some technical tips and instructions to help you get started with downloading data. If you need further help using the new portal or download tool, please contact us through the Contact link in the bottom menu.

### **New Download Features:**

- You can use the same credentials to sign in to both the Answer ALS data portal and download tool.
- You need to define a destination folder for downloading files. This can be local storage, network storage, or Azure Blob storage. Once your destination is selected, the download tool will save files there each time you download data. In addition, the tool will inspect your download folder for any files that were previously downloaded. If the files were downloaded before, the tool will skip downloading them again. This helps to save storage space and time with your downloads.
- The files in your download queue can be reordered or skipped at any time.
- Our tool downloads a single file in multiple concurrent threads and supports download resuming on a per-file basis.
- Closing the application will stop your download progress (daemon mode is not supported).
- You can run our download tool on Windows 10, Mac OS, Ubuntu 20.04 LTS, Debian 10.4, CentOS Linux 8.
